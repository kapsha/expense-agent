# Expense Agent

A single-user expense tracker that processes receipt images through a supervised agent pipeline, classifies spend, and compares it against monthly budgets in INR.

## Language

### Input

**Receipt**: A JPG or PNG image of a purchase receipt submitted by the user. The raw input to the pipeline.
_Avoid_: invoice, bill, scan

**Merchant**: The business or vendor named on a receipt.
_Avoid_: store, vendor, seller, shop

**LineItem**: A single product or service entry on a receipt, consisting of a description and an amount.
_Avoid_: item, line, product, entry

**PaymentMode**: How the transaction was settled. One of: `cash | card | upi | wallet | netbanking | unknown`.
_Avoid_: payment method, payment type

### Classification

**Category**: The spend classification assigned to an expense. One of: `food | entertainment | fuel | transport | utility | medical | groceries | other`.
_Avoid_: type, tag, label, spend type

### Output

**Expense**: A processed receipt stored as a record in `expenses.json`. Contains all extracted fields plus the assigned category and the date it was processed.
_Avoid_: transaction, record, entry

**Usage**: The aggregate token consumption (input + output) and estimated cost in USD across all subagents for a single receipt run.
_Avoid_: tokens, cost, spend (use "spend" only for money budgets, not token costs)

### Budgeting

**Budget**: A monthly spending limit set per category, denominated in INR, stored in `budgets.json`.
_Avoid_: limit, cap, allowance

**BudgetStatus**: The state of a category's month-to-date spend relative to its budget. One of: `under` (< 80%), `warning` (≥ 80%), `over` (≥ 100%).
_Avoid_: status, health, state

**Recommendation**: An actionable, merchant-aware suggestion generated by the Advisor when a category reaches `warning` or `over` BudgetStatus.
_Avoid_: advice, tip, suggestion, alert

### Agent Architecture

**Supervisor**: The orchestrating agent that sequences the Extractor, Classifier, and Advisor in order, aggregates their Usage, and returns a single result to the API.
_Avoid_: orchestrator, coordinator, main agent

**Extractor**: The subagent responsible for converting a receipt image into structured fields (merchant, amount, currency, date, paymentMode, lineItems).
_Avoid_: parser, OCR agent, vision agent

**Classifier**: The subagent responsible for assigning a Category to an expense based on the merchant name and line items.
_Avoid_: categoriser, tagger, labeller

**Advisor**: The subagent responsible for generating Recommendations by comparing category totals against budgets and referencing merchant history.
_Avoid_: recommender, budget agent, analyst
